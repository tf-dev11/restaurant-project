# Restaurant of Draven

A modular, single-page restaurant and bounty board web application inspired by *League of Legends*, built using vanilla JavaScript DOM manipulation and bundled with Webpack.

## Features
- Dynamic tabbed browsing (`Home`, `Menu`, and `Contact`) rendered completely via JavaScript ES6 modules.
- Custom bounty pricing board and Noxian arena hours.

## Built With
- Vanilla JavaScript (ES6 Modules)
- HTML5 & CSS3
- Webpack
